# elz-site-bp

A simple CLI tool for quickly scaffolding website starter projects with a clean boilerplate structure.

---

## Installation

Install the package via npm:

```bash
npm i elz-site-bp@latest
```

Create site blueprint in root directory:

```bash
npx create-site .
```

Create site blueprint in sub-directory:

```bash
npx create-site <name>
```

Automatically installs package elz-ui UI library.
